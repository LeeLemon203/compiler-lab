关于本项目

编译原理实验平台 - 基于C/C++实现，前端可视化展示

📁 项目文件结构

compiler-lab/
├── index.html          # 主页面
├── style.css           # 样式文件
├── app.js              # 页面切换
├── dfa.js              # 实验一：DFA模拟器 (对应 dfa.cpp)
├── scanner.js          # 实验二：词法分析器 (对应 scanner.c)
├── lr0.js              # 实验三：LR(0)项目集 (对应 lr0.c)
├── dfa_in_1.txt        # 实验一 DFA配置
├── dfa.txt             # 实验二 DFA规则
├── test.src            # 实验二 测试源码
└── grammer.txt         # 实验三 文法规则

📐 实验一 (dfa.cpp)

  • 加载 dfa_in_1.txt 五元组配置
  • DFA合法性检查：开始状态、接受状态、转换表完整性
  • 枚举长度≤N的所有接受字符串 (BFS)
  • 判断输入字符串是否被接受

🔡 实验二 (scanner.c)

  • 加载 dfa.txt 词法规则
  • 识别标识符(ID)、整型常量(INT)、浮点常量(FLOAT)
  • 识别运算符: = + - ; .
  • 输出格式: (Token类型, 原始单词)

🔍 实验三 (lr0.c)

  • 加载 grammer.txt 文法规则
  • 增广文法 (添加 S' → S)
  • 计算闭包(Closure)和Goto转移
  • 生成LR(0)项目集规范族
  • 检测移进-归约和归约-归约冲突
  • 输出GOTO图
